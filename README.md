# Medical Platform – Pneumonia Detection

##  Description

Cette plateforme médicale permet d'analyser des radiographies pulmonaires afin de détecter automatiquement la présence éventuelle d'une pneumonie.

Le projet combine une application web avec un modèle de **Deep Learning** pour effectuer la classification des images en deux catégories :

- **NORMAL**
- **PNEUMONIA**

Le projet a été réalisé dans un contexte académique afin d'explorer l'utilisation de l'Intelligence Artificielle et du Deep Learning dans le domaine médical.

##  Intelligence Artificielle

Le projet utilise plusieurs approches pour l'analyse des images médicales :

- **CNN (Convolutional Neural Network)** pour la classification des radiographies.
- **VGG19** pour les expérimentations basées sur le Transfer Learning.
- **Apache Spark** pour le traitement et l'expérimentation sur les données.
- **PyTorch** pour la construction et l'utilisation du modèle de Deep Learning.
- **Monte Carlo Dropout** pour obtenir une estimation de l'incertitude lors des prédictions.
